# 🏏 FanPlay – Interactive Cricket Experience

FanPlay is a responsive web application designed to enhance fan engagement during live cricket matches. Instead of passive viewing, users can actively participate through predictions, polls, AI chat, and fun commentary.

---

## 🚀 Features

- 🎯 **Prediction Game**  
  Predict the outcome of the next ball (Run, Wicket, Dot Ball)

- 📊 **Fan Polls**  
  Vote and see live percentage results

- 💬 **AI Fan Chat (Simulated)**  
  Interactive chat experience with cricket-based responses

- 🎙️ **Commentary Generator**  
  Generate fun and engaging cricket commentary

- 📊 **Live Score Updater**  
  Manually update team names and scores
